# 米高商业化方案

> v1.0 ｜ 2026-08-30 ｜ **状态：方案已定，暂不落地 —— 等 POC 结束后按本方案实施**
> 关联文档：[pricing-design.md](pricing-design.md)（收费设计细则）· [business-plan.md](business-plan.md)（战略蓝图）

## 一、战略与目标

### 1.1 AI First 战略（北极星）

| 原则 | 含义 |
|------|------|
| 产品体验足够好 | 对话式一切、开箱即用、响应快、不打断生意；转人工是兜底不是常态 |
| 产品门槛足够低 | 客户自助开通，不依赖销售/实施；行业模板一键套用、当天上线 |
| 迁移成本低 | 从微信/Excel 迁移不费劲（Excel 导入、小程序现成、模板应用） |
| 人工介入成本低 | 公司侧每个环节 AI 兜底，人只处理 P0（交付、支持、运营全部 AI 化） |

> 门槛低 ≠ 价格低：低门槛靠产品（自助/模板），不靠贱卖。价格锚点仍是客服成本（6~8 万/年）。

### 1.2 经营目标

- **收费目标**：前期「订阅年费 + AI 流量包」；未来按条件演进到结果分成（见第四节）。
- **利润目标**：年利润 ¥100 万。在"成本 = 云 + LLM"前提下（AI 原生经营）：
  - 首年 **~125 家**新客户（含开店包一次性净利）；
  - 稳态（第 2 年起）**~200 家**付费客户（详见第五节单位经济模型）。

## 二、商业模式（前期定稿）

**前期收费 = 订阅年费（含年度 AI 流量）+ 超量流量包（加油包）**，全部以年为单位，无免费版、无月付档。

### 2.1 计费语言

- **AI 流量** = AI 干活量（像手机流量包：套餐 + 加油包心智），客户看"今年还剩多少流量"；
- 内部换算：**1G AI 流量 = 100 万 tokens**（系数放配置可调，不影响对外价）；
- 计量口径：每次 LLM 调用（含意图分类、ReAct 循环、自修复、总结、图片识别等全部幕后调用）的 input+output tokens 计入。

### 2.2 价格梯度（v3.2 定稿，详见 pricing-design.md）

| 档位 | 年费 | AI 流量/年 | ≈ 完整咨询量 | LLM 成本/年 | 毛利 |
|---|---|---|---|---|---|
| 基础版 | ¥3,980 | 120G | ~1,200 次（日均 3~4） | ~¥540 | 86% |
| 专业版 | ¥7,980 | 360G | ~3,600 次（日均 10） | ~¥1,500 | 81% |
| 旗舰版 | ¥15,980 | 960G | ~9,600 次（日均 26） | ~¥3,960 | 75% |
| 加油包 | ¥59/1G | 即买即用 | ~10 次 | ~¥4 | 93% |

- 一次性：标准开店包 ¥2,000~5,000（二郎神 AI 交付）· 深度定制另议 · 首年组合 9 折；
- 保障：首 14 天不满意全额退款（无免费版但给兜底）；
- **不设人工坐席概念**：人工转接全版本标配、不限人数（按坐席收费已被行业淘汰，AI 无"座位"）；
- 超量策略：80% 预警 → 转人工 + 引导加油包 →（旗舰可配硬停），不硬断生意。

## 三、AI First 能力差距与建设路线

> 现状核查结论：商家入驻已 AI 自动甄别秒级开通（人工审批页已废弃）、商品 Excel 导入已有、订单已有"AI 渠道"来源标记雏形。

| 优先级 | 能力 | 现状 | 落地内容 |
|---|---|---|---|
| **P0 商业化地基**（不做没法收钱） | 计量 + 订阅 + 配额 | cost_tracker 进程内、仅告警（审计 A2） | `llm_usage` 表、`tenant_subscription` 表、年度配额硬阻断、Redis 分布式累计 |
| | 米高收款通道 | 现有 Finance 是商家收客户的 | 年费/加油包支付（微信支付商户号/对公）+ 发票 + 到期/续费管理 |
| | 生产就绪收尾 | 审计 06：~74% | 剩余 26% 上线前补完 |
| **P1 AI First 门槛** | 端到端 AI 自助开店 | 注册✅ → 后续未闭环 | 行业模板一键套用 + **知识库自动生成**（最大单点）+ 小程序自动上线 |
| | 用量看板 + 加油包购买 | 无 | admin-web 年度流量进度条、加油包下单 |
| | 迁移工具补齐 | 商品导入✅ | 客户/订单 Excel 导入 |
| | AI 客户支持通道 | 无 | 米高自己的客户问题先进 AI，人工只兜 P0（支持成本 ¥500→¥100） |
| **P2 规模化/未来** | 会话级订单归因 | "AI 渠道"雏形 | session → 订单 → GMV 闭环（结果分成地基） |
| | 公司经营看板 | 无 | ARR/续费率/毛利/流量消耗仪表盘 |
| | 行业模板包 | 二郎神真值沉淀中 | 模板授权费（第二家店边际成本≈0） |

## 四、收费模式演进路线（未来，暂不实施）

| 阶段 | 模式 | 计费语言 | 触发条件（同时满足） |
|---|---|---|---|
| L1 当前 | 订阅年费 + 流量包 | 成本语言（AI 用了多少） | —（已定稿） |
| L2 演进 | 按 AI 解决量 | 业务语言（AI 解决了多少活） | 行业共识方向，随产品成熟自然引入 |
| L3 未来 | 成交额分成 / GMV 抽成 | 价值语言（AI 帮我赚/省了多少） | ① 归因系统跑稳 ≥3 个月 ② 有 3~5 家续费满一年客户 ③ 客户主动问"能否按成交分" |

> 米高独有的分成抓手：小布能直接下单（AI 会话 → 订单闭环），通用客服 SaaS 做不到。

## 五、单位经济模型（成本 = 云 + LLM）

### 5.1 单客户年账

| 参数 | 取值 | 说明 |
|---|---|---|
| 客户结构假设 | 基础 60% / 专业 30% / 旗舰 10% | POC 后校准 |
| 平均年费 | ¥6,380 | 加权 |
| 平均 LLM 成本 | ~¥1,170/客户/年 | 加权（基础 ¥540 / 专业 ¥1,500 / 旗舰 ¥3,960） |
| 订阅毛利 | ~¥5,210/客户/年 | |
| 开店包净利（一次性） | ~¥3,000/新客户 | 二郎神 AI 交付，成本仅算力 |
| 固定成本 | ~¥2~5 万/年 | 云 ¥2~3 万 + AI 研发算力 ¥0.5~2 万 |

### 5.2 年利润 ¥100 万所需客户数

| 阶段 | 计算 | 所需客户数 |
|---|---|---|
| 首年（全新增，含开店包） | (100 万 + 3 万) ÷ (5,210 + 3,000) | **~125 家** |
| 稳态（第 2 年起，纯续费） | (100 万 + 3 万) ÷ 5,210 | **~200 家** |

敏感性：客户结构偏专业/旗舰（40/40/20）时稳态仅需 **~150 家**；续费率 80%→90%，所需客户数再降 ~10%。

> 前提（AI 原生经营）：获客免费（AI 销售 + 口碑 + POC）、交付 AI 化、支持 AI 化。一旦引入投放/人力，模型需重算。

## 六、POC 计划（当前阶段，暂不落地开发）

> 目的：用真实数据校准模型假设，验证支付意愿，跑通 AI 自助交付雏形，产出一套"POC 后照此落地"的基准。

### 6.1 范围与对象

- 1~2 家标杆布艺店（免费换案例，延续 business-plan Q1 打法）；
- 交付走"二郎神 AI 化"流程，同时验证知识库自动生成的可行性。

### 6.2 要验证的假设（POC 数据采集）

| 假设 | 当前模型值 | 采集手段（无需开发） |
|---|---|---|
| 单店日均咨询量 | 3~27 次/店 | 人工统计会话量 |
| 每会话流量消耗 | ~10 万 tokens/会话（0.1G） | 现有 `cost_tracker` 结构化日志 + SLS 采集，无需新开发 |
| 转人工率 / AI 解决率 | ROI 话术依据 | 会话记录人工标注 |
| 价格支付意愿 | 3,980 / 7,980 / 15,980 | 直接问价测试 |
| "AI 流量"概念理解度 | 老板娘零学习成本 | POC 中观察/访谈 |
| 知识库自动生成可行性 | 行业模板一键套用 | POC 交付中实测 |

### 6.3 POC 产出（校准基准）

1. 校准后的场景消耗表（每会话真实 token 分布）；
2. 校准后的价格/配额（如果实际用量远超/远低于模型）；
3. 客户案例（转人工率↓ / 成交额↑ 的 ROI 素材）；
4. 知识库自动生成可行性与人工兜底量；
5. 续费意愿信号（是否愿意 ¥3,980~15,980 续约）。

## 七、落地触发条件（POC 结束后）

三个条件同时满足即开始按本方案落地：

| 条件 | 含义 |
|---|---|
| ① POC 数据校准完成 | 场景消耗表/咨询量分布/价格档位定稿 |
| ② POC 客户有续费意愿 | 至少 1 家愿意付费续约（哪怕是基础版） |
| ③ 生产就绪收尾完成 | 审计 06 剩余项补完 |

**落地顺序（POC 后）**：P0（计量+订阅+配额 → 收款通道 → 生产收尾）→ P1（自助开店/看板/迁移/AI 支持）→ 正式收费上线 → 按增长推进 P2。

## 八、关键决策记录（ADR）

| 决策 | 结论 | 理由 |
|---|---|---|
| 计费单位 | AI 流量（token 内部计量） | 老板可理解；按用量公平；避免会话深浅不均 |
| 收费形式 | 纯年费、无免费版、全部年口径 | 现金流稳、客户只记一个数；低价锚点冲决策门槛 |
| 价格档位 | 3,980 / 7,980 / 15,980 + 加油包 59/G | 客服成本 6~8 万的 5%~27%；毛利 75%~86% |
| 人工坐席 | 不设坐席概念，人工转接全版本标配不限 | 按坐席收费与 AI 经济学冲突；限制无收益且伤信任 |
| 超量策略 | 转人工为主、硬停可配 | 生意优先；硬停补审计 A2 |
| 获客入口 | 14 天退款承诺 + 标杆 POC + 演示租户 | 无免费版但不卡冷启动 |
| 落地时机 | 方案定稿暂不落地，POC 结束后实施 | 用真实数据校准后再投入开发 |
