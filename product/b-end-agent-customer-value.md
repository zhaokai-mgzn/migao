## 一、一句话定位（最高层）

> **它不是助手，是一个「不会累、不会走、不会忘的运营总监」。**

小企业最大的问题从来不是「没有数据」，是**没有管理机制**：
没有周会、没有复盘、没有预警、没有交接文档、没有统一的对外口径 —— 全靠老板的记忆和唠叨。

请一个运营总监：年薪 20~30 万，还要管人、会走、需要磨合。
它的年薪含在 ¥3,980~15,980 里。

**它干的活，就是一个运营总监每天该干但没人干的那些事：**
每天巡检 → 发现异常 → 跨域分析 → 统一口径 → 沉淀知识 → 定期复盘。

> **对客户的原话**：「你招不起一个运营总监，但它干的正是这份活。」

## 二、四个「不用」——价值的真实形态

老板真正买的不是「功能」，是**四种从身上卸下来的负担**。

### 不用想起来（心智带宽）

**这是最贵的一条，也是最没人讲的。**

老板最稀缺的不是时间，是**「不用一直惦记」**。而「想不起来」比「做得慢」贵一百倍：

| | 代价 |
|---|---|
| **做得慢** | 8 分钟 vs 5 秒，差 8 分钟 |
| **想不起来** | 一个月都没查，差一个月 |

**具体价值点：**

| 价值 | 场景 | 现状 |
|---|---|---|
| **异常预警的「提前量」** | 超期 3 天后发现只能赔钱；超期前 3 天预警可以补救。**同样一个问题，提前量 = 可行动空间** | ✅ 已交付（日报 + 规则引擎） |
| **沉默流失的显性化** | 客户不是「走了」，是「悄悄不来了」。**没人会通知你「这个客户 11 个月没下单了」** | ✅ 已交付（客户价值视图） |
| **不用记着去看** | 库存、交期、欠款、退货率——不用每天惦记着查，异常会来找你 | ⚠️ 日报已交付，**外推送未建**（需主动登录后台） |

> **客户原话**：「上个月那批货超期了 5 天，我是客户投诉才知道的。」
> **它给的是**：在客户投诉之前知道。

### 不用翻找（启动成本）

关键洞察：**省的不是 8 分钟，是「开始查」的那道门槛。**

老板不查，不是因为查要 8 分钟，是因为**为了一个模糊的疑问去翻 4 个页面，他根本不会开始**。

| 价值 | 场景 | 现状 |
|---|---|---|
| **跨域视图** | 「这个客户值不值得留」= 订单 + 售后 + 标签 + 复购，四个页面拼 | ✅ 4 个视图已交付 |
| **一句话到答案** | 不用先知道「去哪个页面」 | ✅ 已交付 |
| **历史决策可追溯** | 「这单为什么是这个价」→ 算料口径 + 计价规则 | ✅ 已交付（引真值源） |
| **复盘自动化** | 月末不用再翻一遍，结论直接生成 | ⚠️ 部分（日报覆盖当天异常，月度复盘待建） |

> **客户原话**：「我知道系统里有，但我懒得去翻。」

### 不用怕（信任与一致性）

| 价值 | 场景 | 现状 |
|---|---|---|
| **统一口径** | 3 个客服对「遮光率 85% 够不够」答案不一样 → 客户体验不一致 = 品牌受损 | ✅ 知识卡片 + 真值源 |
| **边界** | AI 不会为了讨好客户乱承诺（物理上没有退款/改价工具）；**员工也不会拿它当挡箭牌** | ✅ 代码级白名单 |
| **举证** | 出问题时说得清（会话留痕 + AI/人工标识 + 转人工快照） | ✅ 已交付（GB-01/02） |
| **心理安全** | **AI 是唯一一个「问蠢问题不会尴尬」的对象**。「这个字段什么意思」问了不怕被老板说。**提问率 ↑ → 学习速度 ↑** | ✅ 页面上下文解释（族 4） |

> **客户原话**：「新人不敢问，问多了显得笨。」
> **它的价值**：让新人敢问，而且答案统一。

### 不用交接（组织记忆）

| 价值 | 场景 | 现状 |
|---|---|---|
| **人走判断不走** | 老客服离职，客户关系和对货的理解一起带走 → 这是小企业最疼的一刀 | ✅ 知识卡片 + 会话沉淀 |
| **新人第一天能上岗** | 不用背颜色 × 售卖方式 × 门幅 × 加工项 | ✅ 行业模板 + 页面解释 |
| **业务不中断** | 员工请假，客户照样能问能答 | ✅ C 端承接 + B 端查询 |

> **客户原话**：「她走了以后，那些老客户就没人跟了。」

## 三、一个只有对话能提供的能力：问「如果」

**报表只能回答「是什么」，「如果」只有对话能回答。**

老板每天脑子里想的其实都是假设：
- 「如果我把赠品取消，复购会不会掉？」
- 「如果这个 SKU 提价 5%，销量会掉多少？」
- 「如果我把这个品类砍掉，现金流会怎样？」

**这些问题的答案，页面给不了，报表给不了，Excel 也给不了** —— 因为它们只能查已发生的事实。

| 状态 | 说明 |
|---|---|
| ⚠️ **规划中** | 当前 B 端 Agent 只能查**已发生的事实**，不能做**假设推演** |
| **但这是最值得做的方向** | 「决策沙盘」是 B 端 Agent 唯一可能超越「查询工具」的地方 |
| **诚实口径** | **现在不能对客户宣称能做到**，否则就是过度承诺 |

> 为什么单独列出来：**这是 B 端 Agent 从「查询框」变成「决策伙伴」的唯一通道。**
> 能力地图族 3 的判据是「加一个问题 = 加一个具名工具」——
> 「如果」类问题需要的是**模拟/推演内核**，不是又一个视图。这是一个新内核的投资。

## 四、按角色的价值表（同一套能力，六个买家）

> 卖给谁、说什么，不能混。

| 角色 | 他真正烦的 | 它给什么 | 对应能力 |
|---|---|---|---|
| **老板** | 什么都要自己盯，心里不踏实 | **不用想起来** —— 异常会来找你 | 日报 + 规则 + 跨域视图 |
| **老板娘** | 客户流失、复购没人跟 | 沉默客户被看见 | 客户价值视图 + RFM |
| **店长** | 被问「这单为什么这个价」，答不上 | 一句话说清依据 | 算料真值源 + 溯源 |
| **客服主管** | 新人答案不统一，客户体验飘 | 统一口径 | 知识卡片 |
| **客服** | 怕答错、怕被问倒 | 随时能问，答案有据 | 页面上下文解释 |
| **新员工** | 不敢问、问不进 | 敢问，学得快 | 同上 |
| **财务/对账** | 说不清哪笔错了 | 可追溯、可举证 | 会话留痕 + 审计 |

## 五、六个容易被忽略的隐形价值

| 隐形价值 | 为什么值钱 | 现状 |
|---|---|---|
| **一致性 = 品牌** | 服务不一致，客户记住的是「这家忽好忽坏」 | ✅ |
| **提前量 = 可行动空间** | 同问题早 3 天知道，结果天差地别 | ✅ |
| **沉默成本显性化** | 悄悄走掉的客户，是最大的隐形漏损 | ✅ |
| **组织记忆 = 企业资产** | 有数据/有记录的企业，比「全在老板脑子里」的企业值钱（融资/被收购时） | ✅ |
| **心理安全 = 学习速度** | 新人敢问，团队成长快 | ✅ |
| **对外谈判力** | 跟供应商/客户谈时，数据一句话就有 | ✅ |

## 六、对客户怎么讲（三句话）

1. **「它不是一个查询框，是你请不起的那个运营总监。」**
2. **「它每天替你巡检，发现你根本不会想起来去查的东西。」**
3. **「你记住：做得慢只差 8 分钟，想不起来差一个月。」**

## 七、诚实边界

| ❌ 不能说 | ✅ 应该说 |
|---|---|
| 「它能告诉你如果提价会怎样」 | 「它能告诉你现在卖得怎样、哪些在赔钱」（假设推演规划中） |
| 「AI 会主动微信提醒你」 | 「登录后台能看到日报」（外推送未建） |
| 「AI 帮你建单改单」 | 「AI 帮你查、分析、批量改价」 |
| 「能替代运营总监」 | 「能干一个运营总监该干但没人干的那些**巡检/分析/复盘**的活」 |
