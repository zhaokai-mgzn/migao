# 米高商业化蓝图 — 布艺行业 AI+电商解决方案

> v1.0 ｜ 2026-08-14 ｜ 定位升级：从「AI 智能客服系统（AIKF）」升维到「布艺行业 AI+电商解决方案」

## 一句话定位

**米高 = 布艺/窗帘商家的 AI+电商经营中台**：以「AI 客服（小布）+ 商家 AI 助手（米宝）」为切入口，覆盖售前咨询 → 下单 → 生产 → 售后全链路，多租户 SaaS 交付。

## 定位升级说明（为什么从「客服」升到「电商」）

| 现状 | 升级后 |
|------|--------|
| AI 智能客服系统（AIKF） | 布艺行业 AI+电商解决方案 |
| 卖点：客服自动化 | 卖点：私域电商经营的 AI 中台 |
| 覆盖：售前/订单/售后问答 | 覆盖：商品(SKU矩阵)→订单→生产→售后→CRM→看板全链路 |

**理由**：米高已有商品 SKU 矩阵（颜色×售卖方式×门幅）、加工项计价、订单全生命周期、售后工单、CRM/RFM、数据看板——本质早已远超「客服」，是一个「私域电商经营中台」。**「AI 客服」只是获客切入口**（最痛、最容易算 ROI 的一环），不是产品边界。

## 价值主张

对布艺/窗帘商家：

| 痛点 | 米高解决 |
|------|----------|
| 定制窗帘 SKU 复杂，客服要背颜色×售卖方式×门幅 | AI 客服自动推荐 + 窗帘尺寸计算 |
| 加工项计价繁琐（锁边/褶皱/挂钩…） | 加工项管理 + 自动计价 |
| 客服 7×24 人力成本高 | 小布 AI 客服，转人工才花人力 |
| 私域（微信）经营缺工具，订单靠 Excel/微信 | 微信小程序 + 订单全生命周期 |
| 老板不懂技术、雇不起 IT | 多租户 SaaS，开箱即用，无自建成本 |

**一句话**：把「一个窗帘店的经营」装进 AI 中台——老板管店、客服管客、AI 干活。

## 产品形态（三端 + 一套交付）

| 端 | 对象 | 内容 |
|----|------|------|
| 微信小程序（C 端） | 消费者 | 小布 AI 客服：售前咨询/下单/物流/售后/图片识别/人工转接 |
| 管理后台（B 端） | 老板/运营 | 商品/订单/售后/CRM/看板/知识库/通知/权限 |
| 客服工作台 | 客服员工 | 转人工会话、快捷回复、工单 |
| 交付体系 | 米高接入 | 二郎神 + 真值设计链路：知识库整理、商品/加工项录入、小程序上线、商家定制 |

## 收费模式（混合定价，先验证再定价）

> 原则：**用「转人工率↓ / AI 解决率↑ / 销售额↑」的 ROI 打动老板，用「实施费 + 订阅 + 增值 + 结果分成」混合收费。**
>
> 可执行细化版见 [pricing-design.md](pricing-design.md)（AI 流量包模式，v2.0：纯年费 3,980/7,980/15,980 + 加油包 59/G）。

| 档位 | 内容 | 参考价 |
|------|------|--------|
| 接入实施费（一次性） | 知识库整理 + 商品/加工项录入 + 小程序上线 + 培训 | ¥1~3 万（用二郎神交付） |
| SaaS 订阅·基础版 | AI 客服 + 订单 + 商品 | ¥1999~3999/月/店 |
| SaaS 订阅·专业版 | + 售后工单 + CRM + 看板 + 多坐席 | ¥3999~6999/月/店 |
| 增值 | AI 调用量超量 / 图片识别 / 高级 RAG 训练 | 按量或打包 |
| 结果分成（进阶） | AI 客服直接带来的成交额分成 | 3~8% |

定价依据：通用智能客服 SaaS 按坐席/调用量/模块收费，正向「按结果收费」演进（[腾讯云](https://cloud.tencent.cn/developer/article/2710603?policyId=1003)、[得助智能](https://www.51ima.com/news/12824.html)）；米高是行业垂直 + AI 原生，可用「转人工率↓、销售额↑」的 ROI 支撑溢价。

## 竞争分析

| 对手 | 做法 | 米高差异化 |
|------|------|-----------|
| 通用客服 SaaS（七鱼/智齿/Udesk/环信） | 通用坐席/机器人，无行业模型 | 布艺垂直：SKU 矩阵/加工项计价/窗帘尺寸计算/面料知识库 |
| 家纺/窗帘行业 ERP | 重本地化、贵、无 AI | 米高多租户 SaaS 轻交付 + AI 原生双 Agent |
| 私域工具（微盟/有赞） | 商城+营销，客服弱 | 米高 AI 客服 + 经营中台一体，客服是切入口 |

## 护城河

1. **布艺行业知识库**：RAG seed 已有窗帘 FAQ/尺寸/面料，越积累越难复制
2. **行业真值模板**：二郎神 8 域真值地图可直接用于米高验收，也是「行业模板包」雏形
3. **双 Agent 垂直打磨**：小布（C 端）+ 米宝（B 端）在布艺场景的意图路由/工具/confirm 已产品化
4. **二郎神交付体系**：快速定制 + 质量闭环，接新商家不改代码（换租户零代码）
5. **多租户 SaaS 底座**：5 层隔离，一个实例服务多商家，边际成本低

## 风险与对策

| 风险 | 对策 |
|------|------|
| 定位升级有 build 缺口（客服→电商：缺商城/交易/营销/履约） | 先以「客服 + 经营中台」切入，交易/营销能力按客户需求增量补齐 |
| 布艺商家付费意愿低、决策慢 | 用「客服人力成本账」算 ROI；先 1~2 家免费 POC 换标杆 |
| LLM 调用成本失控 | 语义缓存 + 模型路由（DeepSeek 主 + Flash 兜底）+ 按量计费转嫁 |
| 双项目资源摊薄 | 米高 SaaS 收入养二郎神服务；二郎神服务反哺米高交付（见 portfolio-strategy） |
| 生产未就绪（~74%） | 用二郎神闭环跑完测试上线阶段，安全审计已在修 |
