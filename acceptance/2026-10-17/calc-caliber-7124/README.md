## 三轮改版（2026-10-17 16:35 起）—— 用户「参考主流设计和我们当前的UI设计风格，重做一版本」

**定稿形态 = 主流设置页的属性行**：一字段一行，**标签 + 口径提示在左、控件在右列**（所有控件共用

| 两侧参考 | 逐条钉住 |
|---|---|
| 主流（Stripe / Linear / GitHub / Vercel） | 一字段一行；控件列**共一条右边界**；行间极细线；区块标题分组 |
| 本仓设计基线（`design-baseline.md` + `components/ui/Input.tsx`） | `h-9 rounded-lg border-neutral-300 focus:ring-2 ring-primary-500/15`；`text-base` 区块标题 / `text-sm` 字段 / `text-xs` 说明；配置页控件**定宽**（`w-40`，不整列拉满，#6857） |
