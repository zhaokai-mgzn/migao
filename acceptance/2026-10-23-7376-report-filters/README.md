## 已知观感项（照实登记，非缺陷）

- 日期框里的占位是浏览器原生的 `mm/dd/yyyy`（Chrome 按**浏览器语言**渲染，页面 `lang` 管不到）；
  中文系统里会显示成 `年/月/日`。这一点控件层改不了，除非自造日期选择器（不划算）。
- 「本月 / 上月 / 近 90 天」是**快捷填充**，填完仍可手改日期；没有「应用」按钮（改完即生效）。

## 未覆盖（照实登记）

- 没有仓库 / 客户 / 业务员维度筛选（要把这三张表的归属键先对齐，属下一段）。
- 区间只到**日**粒度（不含时分）；默认「全部」而不是「本月」（不改变既有数字）。
