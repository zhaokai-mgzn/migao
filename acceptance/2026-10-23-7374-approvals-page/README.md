## 本轮从截图里抓出并修掉的 3 处排版问题

1. **单元格之间没有间距**：首版「王小美2026-10-23 10:00」贴成一串 ⇒ 所有列补 `pr-4`。
2. **短词被折行**：「盘点差/异」「已使/用」竖着排 ⇒ 类型/申请人/状态/徽标补 `whitespace-nowrap`。
3. **裁决说明被切掉**：裁决人与说明挤一行，说明整段被列宽切掉 ⇒ 改成「人名 · 时间」一行 + 说明另起一行截断，
   且裁决时间省年份（`10-22 16:10`）以留出分钟位。
