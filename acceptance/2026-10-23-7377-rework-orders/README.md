## 读图判定（逐条「看到了什么」）

| # | 验收点 | 读数 |

| 1 | 菜单落位 | 侧边栏「生产管理」组内顺序 = 作业看板 → 智能派单 → 计件工资 → 质检记录 → **返工单**（紧跟质检记录：判定 → 要返工就开单），图标为扳手，当前项高亮；面包屑 = 生产管理 / 返工单 |
