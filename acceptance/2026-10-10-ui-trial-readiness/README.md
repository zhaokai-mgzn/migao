## 判定口径（本轮实测踩出来的 4 条，判据/探针照此写）

1. **几何「被吃」必须做"摘掉浮球"对照，且对照要断言"该点命中元素 == 该元素本身或其内部节点"**。
   写成"命中元素是它的**祖先**也算"（`el2.contains(e)`）会把**被 `overflow` 裁掉**的元素误判成"被浮球吃" ⇒ **假红**。
2. **矩形相交 ≠ 被吃**：被 `overflow-x-auto` 裁掉的单元格本就点不到，不算被吃。
3. **瞬时 UI（toast／提示条）必须在其存活窗口内采样**（本仓 toast ~4s）：晚读会得到"没有提示"的**假绿**；反之判"失败面无持久信号"也要**等 toast 过期后再看**（≥6s），否则把瞬时 toast 当成持久面。
4. **`grep` 命中数不是判定依据**：命中处可能是**注释里描述旧形态**（本轮因此在 ①②③ 上差点误判"未修复"）。必须看命中处的上下文。

## 不覆盖（照实登记，别读成"全验过"）

- **真机**（iOS/Android 实机、微信内置浏览器）与**真实扫码枪/打印硬件**；
- **`bmini` / `worker-h5` 的线上内容级行为**（本仓只有 H5 产物的静态面与组件级读数；`bmini` 底栏标签 10px 属**运行时注入 CSS**，在机械判据面外）；
- **报工/发货等写操作的提交步骤**（有意不点，避免污染客户数据）；
- **1680×1050** 断点的运行时几何（1440×980 / 1280×800 / 1920×1080 已跑）；
- **需交互才出现的节点**（展开行、下拉、弹窗内）不在 S3/S6 采样面；
- **审美**（"好看/商务感"）与**服务端下发的展示文案**（后者属后端/agent 侧）。
