## 一条命令跑完整轮（铁律 10：同一串动作做过 ≥3 次就收敛成命令）

```bash
# 从**任意 worktree** 调用都行（脚本会反解到主检出；见下「自证」）
RESET=1 PHASE=post-fix bash acceptance/2026-10-10-ui-trial-readiness/run-all.sh
```

- `RESET=1`：先复位 dev server（`scripts/dev-web-reset.sh`：杀实例 → 三类缓存一起删并**断言清空** → 只起一个 → 等 `/login` **与** `/dashboard` 双 200）；复位失败**直接停**（否则后续读数会假）。
- `PHASE=<名字>`：本轮读数落到 `evidence/S12-<名字>.json`（**不给则 `latest`**）—— 文件名按阶段区分是硬要求，写死一个名字会让下一次运行**静默覆盖**上一次证据。
- **不要用管道包住本脚本**（`| tail` 会吞掉退出码 —— 本批实测踩过三次）。

## 判定口径（实测踩出来的，判据/探针照此写）

1. **几何「被吃」必须做"摘掉浮球"对照，且对照要断言"该点命中元素 == 该元素本身或其内部节点"**。写成"命中祖先也算"会把**被 `overflow` 裁掉**的元素误判成"被浮球吃" ⇒ 假红。
2. **矩形相交 ≠ 被吃**：被 `overflow-x-auto` 裁掉的单元格本就点不到，不算被吃。
3. **瞬时 UI（toast／提示条）必须在其存活窗口内采样**（本仓 toast ~4s）；判"失败面无持久信号"要**等它过期（≥6s）**再看，否则把瞬时 toast 当成持久面。
4. **`grep` 命中数不是判定依据**：命中处可能是**注释里描述旧形态**。必须看命中处上下文。
5. **断言要瞄对元素**：`document.querySelector('aside')` 拿到的是**收起态主导航（64px）**，不是会话列表侧栏（256px）⇒ 瞄错会"修完也假红"。查父子关系用「失败块的**父容器**」当参照。
6. **触发面要精确到与病灶同源**：例如冻结列穿透只在**勾选选中态**发生、**hover 不触发**（真机四态实测）。判据若照 hover 写 ⇒ **永远绿的空断言**；照 hover 修 ⇒ **过度修改**。
7. **探针脚本必须有收尾**（`b.close()`），否则进程不退、白等（实测空耗 10 分钟）；**macOS 没有 `timeout` / `setsid`**。
8. **shell 里 `$VAR` 紧跟非 ASCII 字符必须写 `${VAR}`**（全角括号的字节会被折进变量名 ⇒ `set -u` 下 unbound variable；本批踩 3 次）。
9. **重定向页不是独立页**（`/processing-orders → /production`、`/agent-workspace → human-sessions`）：识别特征是"读数与目标页逐值相同"。
