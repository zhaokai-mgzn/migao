# S32：**部署新鲜度**（客户试用拿到的到底是哪个版本）—— 一条试用阻断级发现

## 结论
| 面 | 线上版本 | 是否含今天的修复 |
|---|---|---|
| **商家控制台 `merchant.migaozn.com`** | 静态 CSS `Last-Modified = 2026-10-10 15:26:37Z` = **本地 2026-10-10 23:26:37 +08** | ❌ **不含**（今天所有合并均在 19:36~19:58Z = 03:36~03:58 +08） |
| **worker-h5 `app.migaozn.com/w/`** | `src/api.mjs` `Last-Modified = 2026-10-10 19:58:33Z` = **03:58:33 +08** | ✅ **含**（#6739 合入 03:58:05 ⇒ **28 秒后**即发布） |

## 方法（内容级，不是只看时间戳）
1. 取商家域 `/login` HTML → 唯一全局 CSS `/_next/static/chunks/20-cmro0iexep.css`（79,125 字节）；
2. 在该 CSS 里搜**今天 #6737 才引入**的 Tailwind token（`primary-50-lit` 及其色值 `f8fafc`）：
   **0 命中**（`bg-primary-50-lit` / `primary-50-lit` / `f8fafc` 全 0）；
3. **同一判据的判别力自证**：把同样的 grep 用在**本地 main 的构建产物**上 ⇒ `bg-primary-50-lit` **10 个文件**、`primary-50-lit` 13、`f8fafc` 10
   ⇒ 探针**本地命中、线上不命中** ⇒ 不是"搜不到"而是"确实没有"。
4. 独立的时间戳口径同向：线上 CSS 的 `Last-Modified` 比今天最早的合并还早约 **4 小时**。
5. 反向对照（另一面）：worker-h5 **未打包**源码可直接拉取 ⇒ `src/api.mjs` / `src/scan-input.mjs` 里
   `normalizeEnterpriseCode`（3 处）/ `shapeMessage`（3 处）/「请核对企业编码」（1 处）**都在线上**，且其 `Last-Modified`
   正好落在 #6739 的合并时刻 ⇒ **worker-h5 是合入即自动发布、商 家控制台不是**。

## 为什么这条是"试用阻断级"
客户试用走的是 **`merchant.migaozn.com`**（不是我们的 main、也不是我本机 :3001）——
**线上包不含 P20（宽表冻结列）、P24（读失败画成空态）、P25（冻结列选中态穿透）、P26（纸面聚合印 0.00）、P27（/orders 读失败印暂无数据）以及本批更早的修复**
⇒ 客户今天试用看到的就是**修之前**的样子。⇒ **试用前必须发布一次商家控制台**。

## 边界（不许夸大）

  （`/login` 只加载登录相关 chunk，拿它搜订单页的串会得到假阴性 —— 我第一版探针就这么错过一次，已作废）。
