# S20：登录页（客户看到的第一屏）设计判定 —— **强通过**

两档视口（1440×980 / 1280×800）真机读数：卡片 420px、两档均**居中**（x=510 / 430）、**无横向溢出**、残留「加载中」=0、**恰好 1 个 `<h1>`**。

| 要素 | 读数（逐字） |
|---|---|
| 品牌块 | 金色圆角 logo + 「观星台」+ 定位句「企业级AI经营管理平台」 |
| 登录方式（分段控件） | 「员工登录 / **账号密码**」｜「管理员登录 / **手机验证码**」—— 子标签让两种模式一眼可辨 |
| 消歧提示 | 「员工请用管理员分配的账号登录。账号形态为「用户名@企业编码」，企业编码见企业管理员设置页（**例如 zhangsan@migao**）。」 |
| 表单 | 账号（占位符「用户名@企业编码」+ 人像图标）/ 密码（「请输入密码」+ 锁图标）/ 深藏青满宽主按钮「登 录」 |
| 出口 | 「还没有账号？请联系企业管理员在「员工管理」中分配用户名与初始密码」 |
| 页脚 | 「© 2026 词元通达 · 观星台」 |

**判为强通过的理由**：① **一个主行动**、无杂物；② 用**具体例子**（`zhangsan@migao`）消掉"账号长什么样"这个最常见的疑惑，而不是让人猜；③ 无账号时有**明确出口**指向「员工管理」；④ 品牌与定位句在场（商务感）；⑤ 页脚有版权主体。
**观察项（不阻塞）**：提示段是两行小号灰字，信息密度偏高；无「忘记密码」路径（按设计由管理员发初始密码 ⇒ 可接受）。
