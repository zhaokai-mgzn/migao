# 配置面字段只有一种写法 —— 版式几何读数（issue #7176，2026-10-18）

## 这是什么

用户裁定「第二张图（阈值试算）可以作为一个标准来参考 …… 一个产品不要出现多种设计和风格样式」。
本目录留**改前 / 改后**两张图 + 可复算的几何读数。

| 文件 | 内容 |
|---|---|
| `before-档位与拼色.png` | **改前**：「档位与拼色」两张 `w-fit` 小表（同一套 class 的静态复现件，内容宽 764） |
| `after-算料口径整页.png` | **改后**：五个区块 = 浅底面板 + 标题 + 说明；「档位与拼色」= 两个并排面板 |
| `layout-probe.html` | 改后形态的静态复现件（class 逐字取自 `components/ui/FormPanel.tsx`） |
| `probe.mjs` | 真实 Chromium 量几何 + 截图；判据：`rightBlank === 0`（否则 exit 1） |

## 读数（CSS px）

| 形态 | 内容宽 | 左卡 | 右卡 | 间距 | **右侧空白** |
|---|---|---|---|---|---|
| 改前（两张 `w-fit` 小表） | 764 | 424 | 246 | 16 | **78** |
| 用户截图（同一屏，逐像素量） | 764 | 423 | 245 | 17 | **79** |
| 改后（两个并排 `FormPanel`） | 764 | 374 | 374 | 16 | **0** |

复现件与用户截图的偏差 < 2px ⇒ 复现件可信（这条对账是**先做**的，不是事后凑数）。

## 怎么跑

```bash
# 1) 生成 CSS（tailwind 3.4，从仓库自己的 globals.css + config 编，不引新样式源）
cd frontend/admin-web
./node_modules/.bin/tailwindcss -i src/app/globals.css -o /tmp/h.css \
  --content "../../acceptance/2026-10-18/design-system-7176/layout-probe.html" --minify
# 2) 把 /tmp/h.css 放到 layout-probe.html 同目录命名 h.css，再量
node acceptance/2026-10-18/design-system-7176/probe.mjs
echo $?   # 0 = rightBlank = 0
```

## 边界（照实登记，§19.1 / §15.7）

- 本目录是**静态复现件**几何，不是真栈截图：本机此刻没有起 `admin-web(:3001) + admin-api(:8080)`。
  复现件的可信度由「与用户截图逐像素对账（< 2px）」承担；**真栈首屏截图**留给下一次部署后的
  读图验收（同一批 class，形状不会变，但**这条没做就是没做**）。
- 本单只改版式：字段、默认值、保存语义、422 逐条理由、算料口径**一字未改**。
- 审美判定仍是 §15.7 读图 + 人裁定（§31.4）；这里只给出**可复算的几何**与**类级守卫**。
