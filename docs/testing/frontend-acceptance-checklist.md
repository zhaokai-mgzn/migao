# 前端修复 L3 人工抽验清单（2026-09-08 批次）

> 依据：acceptance-protocol（§1.2 L3 档 = 只能人判的验收点，AI 不得代判）。
> 用途：今天合并的前端修复属「用户可见渲染/交互」类，API 级验收看不见，需人工在
> 产品里按本清单抽验。每项格式：**入口 → 操作序列 → 预期行为**。

## 1. #3022 米宝面板缩放防冻结

- 入口：B 端 admin-web 米宝对话面板
- 操作：① 多次双击面板缩放把手 → ② 拖拽改变尺寸到极端小/大 → ③ 切页面再回来
- 预期：面板永不冻结/白屏；双击恢复默认尺寸；缩放后残留尺寸被视口钳制，不会撑破布局

## 2. #3024 订单优惠/实收双向联动 + 侧边栏高亮

- 入口：admin-web 订单编辑/创建页
- 操作：① 输入优惠金额 → 实收款应联动变化且**优惠金额可手动输入**（不再锁死）→ ② 直接输入实收款 → 优惠金额反向联动 → ③ 点击侧边栏各菜单项
- 预期：双向联动数值正确；侧边栏当前页高亮唯一且不串位；米宝面板视口不溢出

## 3. #3037 米宝交互组件渲染三态固化（admin-web）

- 入口：B 端米宝对话（可交互组件：choice/confirm/form 卡）
- 操作：① 让米宝弹一张 choice 卡（如加工项选择）→ 点选后**刷新页面** → ② 历史消息回看
- 预期：已作答的卡片刷新后保持**只读态**（已选内容可见、不可再点）；未作答卡片保持可交互；同一会话内卡片渲染态稳定——**不会一会可操作一会只读**；卡片内容不含 `<interact>` 原始 XML

## 4. #3039/#3041 C 端交互组件固化 + 下单防连点（mini-app/bmini-app）

- 入口：C 端小程序下单/咨询流程
- 操作：① 表单/确认卡快速连点多次 → ② 刷新后回看历史
- 预期：提交锁生效（连点只发一次，无重复下单）；历史消息完整透传交互卡（刷新后不消失）；流式回复中卡片不可误点；XML 兜底无原始标签泄漏

## 5. #3043 翻页协议自然语言化（admin-web MessageList）

- 入口：B 端米宝对话，加工项选择器翻页
- 操作：① 弹出加工项 choice 卡 → 点「下一页/上一页」
- 预期：用户消息气泡显示**「查看第2页」等自然语言**，绝不再暴露 `__PAGE__|processing_item_query|{...}` 原始协议串；刷新后历史同样显示自然语言
