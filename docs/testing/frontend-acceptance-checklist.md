## 剧本

### 1. #3022 米宝面板缩放防冻结

- 操作：双击面板缩放把手 → 拖拽到极端尺寸 → 切页再回
- L1 断言：页面无 `pageerror`；缩放后容器宽高被钳制（≤ 视口）；双击恢复默认尺寸
- UA：截图确认面板未错位/未白屏

### 2. #3024 订单优惠/实收双向联动 + 侧边栏高亮

- 操作：输入优惠金额 → 读实收款（应联动）；直接改实收款 → 读优惠金额（应反向联动）
- L1 断言：优惠金额 input 非 `disabled`；两个字段数值满足 `实收 = 应收 - 优惠`；
  点击侧边栏各菜单 → 高亮类名唯一对应当前项
- UA：截图确认无样式错乱

### 3. #3037 米宝交互组件渲染三态固化（admin-web）

- 操作：弹 choice 卡（加工项）→ 点选 → **刷新页面** → 回看历史
- L1 断言：刷新后已作答卡渲染只读态（交互控件 disabled/只读，选中内容可见）；
  未作答卡保持可交互；消息文本不含 `<interact` 原始 XML
- UA：截图对比刷新前后渲染态一致（不会一会可操作一会只读）

### 4. #3039/#3041 C 端交互组件固化 + 下单防连点（mini-app/bmini-app）

- 操作：表单/确认卡快速连点 → 刷新回看历史
- L1 断言：连点只触发一次提交（无重复下单记录）；历史消息透传交互卡（刷新后不消失）；
  流式回复中交互卡不可点（门控）；无 XML 标签泄漏
- UA：截图确认提交锁与卡片态

### 5. #3043 翻页协议自然语言化（admin-web MessageList）

- 操作：加工项 choice 卡 → 点「下一页/上一页」
- L1 断言：用户气泡文案为「查看第N页」等自然语言，**DOM 中不含 `__PAGE__|` 原始协议串**；
  刷新后历史同样为自然语言

### 6. 本次验收观察项（可选）

- S6 主图确认卡：图片字段显示文件名而非完整 URL（P3 优化项；如采纳，AI 一并验证改后行为）
