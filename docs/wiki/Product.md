## 1. 一句话定位

**观星台 = 面向布艺 / 窗帘商家的多租户 AI 经营平台。**
顾客侧由 **元元** 提供 7×24 智能客服与下单；经营侧由 **黄金策** 覆盖商品、订单、生产、
质量、仓储、财务与供应链；商家在观星台后台、顾客小程序、商家小程序与员工端之间协同。

## 2. 为什么不再用「智能客服」做系统定位

| 阶段 | 口径 | 问题 |
|------|------|------|
| 旧 | AI 智能客服（旧口径） | 只描述了「顾客对话」这一个面；系统实际已覆盖生产、仓储、财务、供应链 |
| 新 | 布艺行业 AI 经营平台 | 智能客服是「客户服务」能力域的一项能力 + 元元这一位 Agent 的职责 |

定位口径沿革：issue #6463（企业级 AI 经营管理平台）→ issue #6525（品牌改名：观星台 / 黄金策 / 元元）。
**拉丁标识符、域名、环境变量保持 `migao` / `MIGAO_*`**，不随中文称呼改动。

## 3. 服务对象与四端

| 端 | 使用者 | 入口 | 主要职责 |
|----|--------|------|----------|
| 观星台管理后台 | 商家管理员 / 员工 | `frontend/admin-web` | 全量经营：报表、客户服务、订单商品、生产、质量、仓储、财务、供应链、组织 |
| 顾客微信小程序 | 终端顾客 | `frontend/mini-app` | 元元对话、算料报价、下单、订单物流、售后、知识卡片、图片识别 |
| 商家小程序 | 商家 / 员工 | `frontend/bmini-app`（小程序编译） | 黄金策移动版、经营一屏、移动坐席 |
| 员工端 H5 / 安卓终端 | 车间工人 | `frontend/bmini-app`（H5 编译，`/b/`）+ 安卓终端 | 扫码报工、入库、发货、返工、计件 |

> `frontend/worker-h5`（线上 `/w/`）是**兼容期旧页**：只服务已印出的纸码，不再新增功能，
> 也不再是任何跳转的目标（判据 = `tests/unit_ci_workflows/test_w_compat_period.py`）。

## 4. 两位 Agent

### 元元（C 端顾客）

| 维度 | 内容 |
|------|------|
| 服务对象 | 微信小程序里的终端顾客 |
| 典型能力 | 商品咨询、窗帘算料报价、下单（短信验证码 + 权威价）、订单与物流、售后受理、知识卡片、图片识别 |
| 能力边界 | 不改价、不取消订单、不退款、不承诺优惠折扣、不报库存数量；报价一律说明为估算 |
| 知识来源 | 只检索本店**已发布**的知识卡片；未命中用通用知识谨慎回答并给出免责 |

### 黄金策（B 端经营）

| 维度 | 内容 |
|------|------|
| 服务对象 | 商家管理员 / 运营 / 客服 / 财务 / 生产岗位 |
| 典型能力 | 经营看板与每日简报、商品与 SKU、订单与加工单、库存与入库、生产与计件、财务与客户、口径卡学习 |
| 可写动作 | 改价、商品改名、批量改价、批量库存调整（可撤销）、通知标记已读、定时提醒 |
| 不做 | 上下架、删除、创建订单、创建商品；改价必须携带改前价并经确认卡二次确认 |
| 学习机制 | 会话中的纠正先落成 `draft` 口径卡，**审核通过后**才进入本企业 prompt；可退役、可追溯来源 |

## 6. 业务闭环（布艺行业纵深）

| 步骤 | 系统形态 |
|------|----------|
| 询价与算料 | 按尺寸、褶皱与工艺计算用料并给出估算报价；加工项与加工费组合单独定价 |
| 下单 | 规格覆盖颜色 × 售卖方式 × 门幅；短信验证码校验；成交单价取商品库权威价 |
| 生产 | 订单生成加工单（按套），工艺路线驱动工序：裁剪（裁床）→ 车位（缝制）→ 后整（烫工及后整）；工人扫码报工 |
| 入库 | 入库单先建草稿（不动库存）；过账后生成批次并按移动加权平均记成本 |
| 发货 | 发货单记录来源与实发数量；区分「物流发货」与「无需物流」 |
| 售后与对账 | 售后六类工单 + 资金流水 / 收支汇总 / 应收对账三张账 |

## 7. 平台保障

- **多租户隔离**：租户身份只取自登录凭证；查询自动按租户过滤；跨租户访问返回 404
- **岗位权限**：管理员 / 客服 / 运营 / 销售 / 财务 / 商品管理员 / 知识编辑等岗位，菜单权限逐人可配
- **操作可追溯**：AI 工具调用与关键业务操作留痕，敏感信息脱敏
- **AI 自动甄别入驻**：敏感信息与非法内容先经规则层过滤，再给出结论；通过后开通租户与管理员账号
- **合规表述**：人机协同机制参考 GB/T 47746-2026 设计；只写「参考 / 对标」，不宣称认证
  （口径见 [gb47746-2026-compliance](gb47746-2026-compliance.md)）
