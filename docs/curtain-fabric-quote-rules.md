# 窗帘用布量计算与计价规则清单（AI 算料工具真值来源）

> 标注：【标】= 行业标准值（可直接编码为默认常量）；【默】= 经验默认值（需商家可配置）。

## 1. 褶皱倍数 N
- 通用：【标】家用帘身常规最佳 2 倍；最低 1.5 倍（低于 1.5 影响美观）；省料可 1.8~1.9 倍。效果：倍数越高褶皱越深越饱满（1.5 平直简约 / 2 标准 / 2.5~3 豪华）。
- 分款式：【标】打孔帘（罗马圈/眼环）1.8~2 倍，默认 2；韩式褶（S 钩/调节钩）2~2.5 倍，默认 2；四爪钩/普通挂钩 1.5~2 倍，默认 2；罗马帘/卷帘/百叶帘 1 倍（硬质折叠无褶皱，按窗宽+包边）。厚重面料（绒/雪尼尔）可降至 1.8~2 倍。

## 2. 门幅（幅宽）与挂向
- 【标】定宽布：幅宽固定、高度不限，窄幅 1.4m、宽幅 2.8m 为基准 → "定宽买高"（竖挂，按高度买米）。
- 【标】定高布：高度固定 2.8m（亦有 2.7/3.0m）、宽度不限 → "定高买宽"（横挂，按宽度买米）。
- 材质差异：遮光布、纱帘多为 2.8m 定高；雪尼尔/绒布多为 2.8m 定宽（部分 1.4m）；棉麻/真丝多为 1.4m 定宽。
- 选型：层高 ≤2.8m 用定高布最省料；层高 >2.8m 或大花型需对花时用定宽布。同条件下 1.4m 定宽用料约为 2.8m 定宽的两倍。

## 3. 用布量精确公式
定义：W=窗宽(m)，H=窗高(m)，N=褶皱倍数，G=门幅(m)。
- 定高布（买宽）：`M = (W + 0.3) × N`（0.3 = 左右各 15cm 覆盖余量；下限可只按 W×N）。约束：成品高 ≤ G−0.3（2.8m 定高上限成品高约 2.5~2.6m），超限改用定宽布。
- 定宽布（买高）：`幅数 P = ceil((W + 0.3) × N / G)`（向上取整）；`每幅长 L = H + 0.3~0.4`（上下卷边+损耗）；`M = P × L`。对花：每幅加 ≤1 个花距，`L = H + 0.3~0.4 + 花距`（或按花距整数倍对齐）。
- 罗马帘：`M = (W + 0.2) × (H + 0.3)`（包边）；卷帘/百叶帘：M ≈ 窗宽×高，无褶皱倍率。
- 规则：幅数一律向上取整；单幅不足须拼幅，拼幅处花型左右对称；对花损耗 ≈ 拼幅数 × 花距。

## 4. 损耗与余量
- 【标】缝边/卷边：侧边止口每边 2~3cm；脚位 8cm + 止口 2cm；上下卷边合计 0.3~0.4m（下限 0.24m）。
- 【标】成品定位：下摆离地 1~3cm、离顶 1~15cm；半高帘高 = 窗框高 + 20~30cm。
- 【标】对花：有花距须对齐，每幅加 1 个花距（常见花距 30~60cm）；车固定折且带花距按宽 ×2.3 倍。
- 【标】缩水率：天然纤维（棉麻丝毛）3%~5%（欧洲标准）；化纤/混纺 <1~2%。裁剪前预缩或按比例加长。

## 5. 加工费（元/米，按面料米数计）
【默】四爪钩/挂钩式 5 元（含布带和钩子）；打孔式 8 元；圆环单钩/韩式褶 10 元；实体店高端 20 元。帘头加工 50 元/米（花边另计）。罗马圈 1~2 元/个，每米布 6 个。安装人工 15~20 元/米，或一口价 100~300 元/次。

## 6. 辅料计价
【默】罗马杆（明轨）15~30 元/米（实木/铝合金）；轨道（暗轨）6~50 元/米，常见 15~35；电动轨道约 160 元/米。布带/孔带 5~15 元/米；四爪钩约 15 元/大包（约百个）；S 钩/调节钩 0.3~1 元/个；绑带 10~20 元/对；花边 5~15 元/米；铅坠/铅线 2~5 元/米。杆长 = 窗宽 + 0.3~0.4m（两端各伸出 15~20cm）。

## 7. 完整算例（窗宽 3m、高 2.7m，2.8m 定高遮光布，2 倍褶皱，打孔安装）
1. 面料：成品宽 = 3 + 0.3 = 3.3m；`M = 3.3 × 2 = 6.6m`。
   - 注意：2.7m 窗高 + 0.3m 卷边 = 3.0m > 2.8m 定高，严格应选 3.0m 定高布或定宽布（定宽算法：`P = ceil(6.6/2.8) = 3` 幅，`L = 2.7+0.3 = 3.0m`，`M = 9.0m`）。以下按用户指定的 6.6m 计。
2. 面料费：6.6 × 30 元/米 = 198 元（遮光布 20~40 元/米）。
3. 加工费（打孔）：6.6 × 8 = 52.8 元。
4. 辅料：罗马圈 6.6×6 ≈ 40 个 × 1 元 = 40 元；孔带 6.6 × 8 = 52.8 元；罗马杆 3.4m × 25 = 85 元；绑带 1 对 15 元。
5. 安装：3.4m × 18 ≈ 61 元。
6. **总价 ≈ 198 + 52.8 + 40 + 52.8 + 85 + 15 + 61 ≈ 505 元**（约 76.5 元/平米窗面积）。
