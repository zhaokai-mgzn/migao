# 米高 Logo 重设计方案

> 2026-08-27 ｜ 现状：`frontend/admin-web` 使用折线 M 图形标，`favicon.svg` 却是「米」字——两处不统一，图形标也未体现行业属性。

## 品牌锚点

| 维度 | 取值 |
|------|------|
| 定位 | 布艺/窗帘商家的 AI+电商经营中台（多租户 SaaS，AI 客服切入）|
| 关键词 | 专业、清晰、温暖、布艺质感（`docs/design/ui-design-spec.md` v8.0）|
| 主色 | Primary-500 `#2F54EB`；织金 Warm-500 `#D48806` |
| 现有资产 | 蓝渐变圆角方块 + 白折线 M；favicon 为蓝底「米」字 |

三个方向**共同保留**现有蓝色渐变底板（`#6E8CFF → #2F54EB`）与 44×44 圆角方块结构，只重绘图形标——对老用户是"进化"而非"换脸"，前端组件几乎零改动成本。

> **2026-08-27 更新**：选定方向 B 后，底板配色经对比评审改选为 **织金暖底**（`#FFC53D → #D48806`），呼应设计规范的"温暖、布艺质感"。配色对比见 `color-comparison.svg`（5 版：蓝底 / 白底蓝标 / 织金暖底 / 蓝金渐变 / 深藏青）。

## 三个方向

### 方向 A ·「米」·星光 — `concept-a-spark.svg`

- 图形：横竖 + 双斜的**八芒星 =「米」字骨架**，圆头收笔如织物纱线；中心金色米粒点芯。
- 语义：东方字标 × AI 星芒；金色点 = 织金质感 + 每粒"米"都是金。
- 优点：与现 favicon「米」字一脉相承，可直接统一两处；几何极简，缩到 16px 依然清晰。
- 风险：八芒星在部分语境读作"星号/设置"，需靠金色点芯+蓝色底板锚定品牌感。

### 方向 B · 帘成 M — `concept-b-curtain.svg`

- 图形：顶部**窗帘杆 + 吊环**，下方白色垂帘自然构成 M，底边波浪如窗帘下摆。
- 语义：一眼认出布艺/窗帘行业，"M" 藏在产品形态里。
- 优点：行业辨识度最高，讲故事能力最强。
- 风险：元素最多，小尺寸（favicon 16px）下吊环细节会糊，需要简化版适配。

### 方向 C · AI 星 M — `concept-c-ai-star.svg`

- 图形：扁平宽顶、圆角的**拱形 M**，中间尖峰上方悬一枚**金色四芒星**。
- 语义：星在峰上 =「高」；星芒 = AI；最接近现 logo 的渐进式升级。
- 优点：现代 SaaS 感最强，与现有折线 M 认知连续，迁移成本最低。
- 风险：行业属性靠后续应用（官网、后台文案）补足，图形本身不说行业。
