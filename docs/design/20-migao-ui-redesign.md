# 20 — 经营看板「织物质感」改版（样板页）

> 关联 issue：#2532。样板页：`/dashboard`（数据看板）。
> 本文档为 DRAFT 的 `design_ref`，沉淀织物质感设计 token 与数据可读性治理口径，供后续页面改版复用。

## 1. 设计方向

- 底色 `#faf7f2`（米白，暖中性）——替换平灰 `#f5f5f5`
- 主色 `#48618f`（靛蓝）——替换默认蓝 `#3b82f6`
- 点缀 `#c06a3e`（陶土）——用于涨势、米宝洞察、次要强调
- 中性色：暖灰阶（`neutral` 50–900）
- 卡片：`rounded-xl` + 软分层阴影（`shadow-sm`）+ 极细描边（`border-neutral-200`）
- 字号阶梯：12 / 13 / 14 / 16 / 20 / 24

## 2. 设计 token

| 语义 | Tailwind token | 值 |
|------|----------------|-----|
| 主色 | `primary.500` | `#48618f` |
| 点缀 | `accent.500` | `#c06a3e` |
| 米白底 | `neutral.50` | `#faf7f2` |
| 暖灰阶 | `neutral.*` | 50–900 |

## 3. 页面结构（样板页）

1. 顶部：页面标题 + 数据更新时间
2. 米宝「今日经营速览」洞察条（一等公民，置于页面顶部）：
   - 订单环比
   - 含加工占比
   - 低库存预警
3. 待处理任务（3 卡片）
4. 经营数据（3 卡片）
5. 订单趋势 / 销售额数据（响应式 x 轴降采样）
6. 近期订单 / 商品销量排行（语义色 chips + 空态治理）

## 4. 数据可读性治理

- **状态 chips**：订单/售后状态映射语义色（`src/lib/status-chip.ts`），禁止整列 `-` 占位。
- **空态**：显示「暂无数据」/「暂无*」明确文案，禁 `-`、`[object Object]`、`NaN`。
- **图表密度**：订单趋势 x 轴刻度按可用宽度降采样（`src/lib/axis-sampling.ts`），1280 宽度下刻度 ≤ 7、无密集重叠。
- **表头防截断**：表格表头 `whitespace-nowrap`，1440×900 与 1280×800 两视口无截断/溢出。

## 5. 响应式边界

- ≥1280：完整优化布局（`lg:grid-cols-2`）
- 1024–1280：降级（单列）
- 多视口页面验收：1440×900、1280×800（取最严）

## 6. 验收口径

- 结构口径（数据渲染/占位/截断/破图/多视口）→ 二郎神页面验收自动判（`page-specs/dashboard.yml`）
- 美学口径（暖色气质/材质感/信息层级）→ 人工拍板 + 视觉模型结构化建议
