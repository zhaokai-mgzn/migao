## 4. 发现并修复的问题：澄清轮护栏未生效（P1）

### 4.1 现象（真实验收暴露）

C-10/B-02 连续模糊意图（"帮我看看"→"就是那个"→"你懂的"）时：
- 第 1 轮弹澄清卡 ✅
- 第 2、3 轮仍继续弹卡/引导追问 ❌ —— **兜底话术（给具体示例+转人工出口）永不出现**

违反护栏设计（issue #2796）：连续澄清 ≥2 轮后应强制示例兜底，而非无限追问。

### 4.2 根因（三层缺陷叠加）

1. **主挂点判定过严**：`intent_router_node` 只把 `source=="low_confidence"` 记为澄清轮，
   但 `GENERAL` 意图在低置信重写豁免清单内——R1"帮我看看"被 classifier 直接判
   `general`（confidence=0.30），首轮澄清**不计数**，兜底整体推迟。
2. **plan_rewrite 路径完全绕过护栏**：澄清卡下发后 `pending_interact_skill` 已设置，
   后续模糊短消息（≤5 字）走 plan_rewrite **提前 return**，护栏挂点
   （条件含 `not pending_skill`）根本执行不到 → 计数永远停留在 1。
3. **兜底话术被 pending_skill 覆盖**：即使护栏改写为 `direct_reply`，
   `route_by_intent` 因 pending_skill 存在又覆盖回 general skill → 兜底不触达用户。

### 4.3 修复（TDD：46 个相关测试全绿，全量 2197 通过）

| 文件 | 改动 |
|---|---|
| `app/graph/nodes.py` | ① 主挂点判定放宽为 `intent==general` 即计澄清轮；② plan_rewrite 分支接入护栏（`pending_skill in (general, customer_general)` 且短消息不含领域关键词→计数，含关键词→清零）；③ `guard_forced` 标记随 route_decision 透传 |
| `app/graph/clarify_guard.py` | `_rewrite_to_example` 附带 `guard_forced=True` |
| `app/graph/nodes.py` | `route_by_intent`：`guard_forced=True` 时不被 pending_skill 覆盖，兜底直达 |
| `tests/test_graph_nodes.py` | 新增 6 例：plan_rewrite 达上限兜底 / 模糊计数 / 领域词清零 / classifier 计轮 / customer_general 计轮 / guard_forced 穿透 |

### 4.4 修复后真实回归（真实 LLM 端到端）

**B 端**（mibao）：
```
R1 帮我看看  → 澄清卡 choice（4 方向）

```

## 5. 遗留问题（线上间歇错误，已记录待线上日志定位）

**B-03 图片建品首轮间歇报错**：`抱歉，遇到问题: KeyError: '"page"'` /
`ValueError: unmatched '{' in format spec`（线上约 1/6 概率复现）。

- 特征：两个报错均为 `str.format()` 解析含 JSON 花括号（`{"page":...}`）字符串的特征；
  复现时首轮无任何 tool_call/text 事件（loading → error）。
- 已排除：本地同代码 40+ 轮循环未复现；部署版本（f1baeec7）与最新 main 的
  ai-agent 代码 diff 为空；全仓唯一 `.format(` 调用（follow_up.py）为死代码。
- 推断：线上环境/时序相关（真实 LLM 返回内容含 `{` 被下游某处 format 解析），
  需要线上服务日志的完整 traceback 才能定位（本地无法复现）。
- 建议：线上 SLS 检索 `[astream_chat] Error` + `session=` 对应 traceback；
  或对 chat 返回内容增加花括号转义兜底。**不阻塞本次护栏修复合入**（非 required check）。

| 维度 | 结果 |
|---|---|
| 澄清卡出现时机 | C 端 10/10、B 端 10/10 正确（该弹时弹、意图明确时不弹） |

| 澄清轮护栏 | 🔴→🟢 验收发现缺陷并已修复，真实回归通过 |
| 已知遗留 | B-03 图片建品首轮线上间歇报错（待线上日志定位，见 §5） |

**验收判定：澄清能力整体达标；验收发现 1 个真实护栏缺陷已修复并回归；
1 个线上间歇错误已记录并给出定位路径。**
