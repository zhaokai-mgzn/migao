## 1. 品牌关系

| 层级 | 名称 | 用法 |
|---|---|---|
| 公司 / 法律主体 | **词元通达** | 合同、发票、官网主体、版权行 |
| 产品 / 平台 | **生意管家** | 登录页、侧边栏、官网、小程序、宣传物料 |
| 顾客侧 AI | **米宝** | 面向顾客的角色名，不单独背平台品牌 |
| 经营侧 AI | **黄金策** | 面向经营者的角色名，不单独背平台品牌 |

- **一个产品名**：用户只需要记住「生意管家」；米宝与黄金策是产品内的角色。
- **公司名承接技术底座**：词元（AI 底座）+ 通达（把能力送到经营现场）。
- **不改的东西**（沿用 issue #6525 的口径）：内部标识符、域名、历史迁移、历史记录、测试数据名。

## 2. Logo：「旦」字方印

图形 = 深靛圆角方印 + 织金「日」圆 + 织金地平线。

| 元素 | 语义 |
|---|---|
| 日（金圆） | 词元 / 每一天的经营数据；也是「生意如日初升」的日 |
| 一（金线） | 经营的地平线、管家的基座；一以贯之 |
| 旦 | 天明、日复一日；管家每天在，生意每天新 |
| 方印 | 可托付的管家之印：信任、契约、责任 |
| 靛蓝 | primary-500 `#48618f` → primary-700 `#2e3d5c`：专业、克制 |
| 织金 | `#f6d27a` → `#d48806`：服务与价值，不抢主体 |

为什么不是「管家铃 / 管家帽 / 钥匙 / 五笔生」：

- 铃、帽、钥匙都是**字面物件**；用户 2026-11-24 的反馈是「简洁、有设计感、立意深远」，
  字面物件会把品牌锁在一个具体形象上，缩到 16px 也容易糊。
- 五笔「生」在 1024 下好看，但缩到 28px 会挤成一团金线，不满足「简洁」。
- 「旦」只有两笔：圆 + 线。28px 仍是「日 + 一」，16px 是「一点一线」；
  意义却是「日复一日 / 生意如日初升 / 管家每天在」，比一个具体物件更耐讲。
- 圆也是**词元**（token）的形；线是**通达**（路 / 基座）。公司名与产品名在同一组两笔里。

> 沿革（同一天两次收敛）：第一版「管家铃」（服务铃 + 底座 + 星芒）→ 第二版五笔「生」
> → 最终「旦」字方印。旧铃与旧「生」资产不再使用，判据会拦住回流。
