> 状态：已实施（issue #9121）｜ 公司：词元通达 ｜ 产品：生意管家

## 1. 品牌关系

| 层级 | 名称 | 用法 |
|---|---|---|
| 公司 / 法律主体 | **词元通达** | 合同、发票、官网主体、版权行 |
| 产品 / 平台 | **生意管家** | 登录页、侧边栏、官网、小程序、宣传物料 |
| 顾客侧 AI | **米宝** | 面向顾客的角色名，不单独背平台品牌 |
| 经营侧 AI | **黄金策** | 面向经营者的角色名，不单独背平台品牌 |

- **一个产品名**：用户只需要记住「生意管家」；米宝与黄金策是产品内的角色。
- **公司名承接技术底座**：词元（AI 底座）+ 通达（把能力送到经营现场）。
- **不改的东西**（沿用 issue #6525 的口径）：内部标识符、域名、历史迁移、历史记录、测试数据名。

## 2. Logo：管家铃

图形 = 深靛圆角方印 + 织金铃身 + 米白底座 + 右上星芒。

| 元素 | 语义 |
|---|---|
| 铃 | 随叫随到的服务：经营有事，管家应声 |
| 底座 | 经营台面：铃放在真实业务上，不是悬空的概念 |
| 方印 | 企业级底座的稳重感与可托付 |
| 星芒 | 词元 / AI 的底座；16px 下退化为一个亮点 |
| 深靛 | primary-500 `#48618f` → primary-700 `#2e3d5c`：专业、克制 |
| 织金 | `#f6d27a` → `#d48806`：服务与价值，不抢主体 |

为什么不是「管家帽 / 钥匙 / 天文台」：

- 帽子与钥匙是字面义，且钥匙天然带「权限 / 安全」语义，容易被读成门禁产品；
- 天文台是旧名「观星台」的字面延续，与新产品名无关；
- 铃是服务业的通用动作，跨行业可延展，不把产品锁在布艺。
