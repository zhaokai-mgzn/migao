# 窗帘生产与计件规则清单（生产模块真值来源）

> 标注：【标】= 行业标准值（可直接编码为默认常量）；【默】= 经验默认值（需商家可配置）。
> 来源：2026-09 客户提供的行业 ERP 系统截图（堡达/壁达软件管理系统 5.40.0 加工单/工序维护/订单录入）+ 客户逐项确认。
> 与 [curtain-fabric-quote-rules.md](curtain-fabric-quote-rules.md) 配套：算料/报价口径见该文档，本文件管生产/工序/计件/物流。

## 1. 订单 → 加工单

- 【标】已确认（含加工项）订单生成加工单，可**一套一单或一单多套**（第 N 套/共 M 套，工程单按楼层/项目拆套）。
- 【默】**两套编号**：内部加工单 ID 与对外单号（日期+流水，如 `CSO260915-02615`，打印给车间）。
- 【标】加工单**打印物含二维码**（单号+套号+部位，token 化、可撤销、记录打印次数）——二维码是扫码报工的入口。
- 【标】部位行字段：部位(布帘/纱帘/帘头) · 类型 · 型号(货号-色号) · 批号 · 单价 · 用料 · 褶数 · 幅数 · 折扣 · 小计；下单行另有：宽 · 高 · 工艺(韩褶/打孔/四爪钩/穿杆) · 打开方式(单开/双开/四开) · 加工类型(定高买宽|定宽买高) · 是否定型 · 货号 · 总褶数 · 褶距 · 理论褶倍/实际褶倍 · 是否对花。
- 【默】**特殊选项清单**（下单勾选，影响用料/工序/计件系数）：余料带回(布/纱)、布绑带、纱绑带、加logo条、加立边、加花边、拼1/2/3次、加铅块、接高、双眼皮接高、扣环、抱枕、防翘扣、一分二、余料做绑带、余料做帘头。
- 【默】保证金机制：保证金余额 / 保证金使用 / 本次收款 / 收款备注（定金制，配合企业收款二维码）。

## 2. 工序库

- 【标】**工序分组**：`裁剪 / 车位 / 后道 / 其他`（不是按阶段，是车间工位分组）。
- 【标】**工序按部位分设**：同一道工序在布/纱/帘头上单价各自不同（韩褶-布、韩褶-纱…）。
- 【默】工序属性：名称、工序分组、单位（米/套/件/个）、排序、部位、距离交期天（排期用）、计件单价（版本化）、特殊选项系数。
- 【标】工序开关：**此工序必须完成才可打包**（完工门槛）、标记生产开始（首工序触发订单进入生产中）、完成时打印水洗标/条码标签/余料用途标签（外贸标签等）、车间电视大屏是否显示。

## 3. 工艺路线（布帘·韩褶，行业实证 11 道）

```
精裁-布 → 布三边 → 韩褶-布 → 上车布-布 → 熨烫-布 → 定型-布 → 复烫-布 → 布帘车被 → 外帘打卷 → 外帘装袋 → 外帘发货
```

- 【默】其他工艺路线按 部位 × 工艺 实例化（韩褶/打孔/四爪钩/穿杆/纱帘/帘头/罗马帘），**条件工序按特殊选项插入**（拼N次→拼-布、加花边→花边工序、定型=是→定型-布等）。
- 【默】工序实例的**应做数量 = 算料引擎输出**（折数/孔数/用料米数/幅数），报工只确认，不手工心算。

## 4. 计件（工资计算）

- 【标】**计件工资 = Σ(报工数量 × 工序单价)**；**单工序一人制**（2026-09 客户确认，无计件人数分摊）。
- 【默】数量口径结构化（非公式字符串）：用料米数 / 成品宽 / 成品高 / 折数 / 孔数 / 幅数 / 套数 / 固定值；条件系数表：特殊选项 → 工序 → 系数（如 一分二 ×1.7）。
- 【默】单价 = 工序 × 部位定价，**版本化**（调价只影响新报工，历史报工按当时价，逐笔可追溯）。
- 【标】**两套账分离**：内部计件（per 工序，给工人）vs 对外加工费（per_meter 按米打包含辅料，收顾客，issue #3005）——互不污染。
- 【默】工资报表 = 报工事件聚合（按人/按期/按单下钻：报工 → 工序实例 → 部位 → 套 → 加工单 → 订单）。

## 5. 扫码报工闭环（核心流程）

```
打印加工单（含二维码）→ 工人扫码 → 工人端显示本部位待做工序（含应做数量）
  → 点「完成」报工（人/工序/数量/时间）→ 工序条推进 + 计件金额累计
  → 全部「必须完成才可打包」工序完成后 → 订单自动进入「生产完成」态
```

- 【标】防呆：幂等（重复扫提示已报）、越站提示（非本工序）、数量上限校验（≤应做数量+合理损耗）、非本部位码提示。
- 【标】一次扫码同时干两件事：**推进工序进度 + 记录个人计件**。
- 【默】弱网降级：扫码页缓存待做清单，离线报工补传。
- 【标】操作记录 = 报工明细（实证：`蒋雪云-定型 11.00`、`李红梅-韩褶 11.00`… 带时间戳）。

## 6. 物流（客户常用物流/快递）

- 【默】**物流类型枚举**：`express`（快递：顺丰/圆通/中通等）/ `logistics`（物流/专线：四季安等）。POC 客户更多选择物流专线。
- 【默】**客户常用物流档案**：客户基本固定选同一家承运商，下单/加工单自动带出、可改。
- 【默】订单/加工单字段：货运方式（类型+承运商）、货运单号；发货动作 = 录入货运单号 → 订单进入已发货，C 端查物流（customer_logistics_track）只查本人已发货订单。

## 7. 客户工艺画像（客户记忆，2026-09 客户强调）

- 【默】客户级工艺偏好档案：`craft_mode ∈ { standard 跟随企业固定工艺算料 / economy 主动省料 / self_quoted 自报用料 }`，连带 开数/定型/档位/物流 等默认值。
- 【默】来源：AI 在报价协商中自动学习（客户自报用料 → 标记 self_quoted）＋ 商家可手动标注；报价时按画像出默认方案并标注「按您上次的习惯」，可改。
- 【标】不同客户差异化：有些客户愿遵守企业固定工艺算料，有些懂工艺的主动报省料方案——由商家裁定最终档位（权限+留痕）。

## 8. 术语表（AI 词汇底座，跨模块统一）

| 术语 | 含义 |
|---|---|
| 打开方式 | 单开（一片）/ 双开·对开（两片）/ 四开（四片）；对开总折数为偶数 |
| 部位 / 帘种 | 布帘 / 纱帘 / 帘头 —— **工序路线的索引键**；「外帘」是加工单打印行部位，**不是**路线键 |
| 部件 / 明细行 | 主布 / **配布边** / 纱 / 加工项 / 加工费（报价与加工单的**明细行粒度**） |
| 加工类型 | 定高买宽（买宽度米数）/ 定宽买高（按门幅幅数×高度） |
| 定型 | 部位级开关：打褶后蒸烫固定褶形；联动价格/工序/计件/质检/包装 |
| 款式 | 单色 / 拼色（拼色 = 主布+配布分料、按折加价） |
| 褶倍 | 名义倍数（如 2.00）与理论/实际褶倍分开记录 |
| 精裁 | 裁剪工序（含裁床输出），布/纱分设（精裁-布/精裁-纱） |
| 计件人数 | 已取消（单工序一人制，2026-09 客户确认） |
| 工艺价 | 对外加工费单价（元/米，含辅料打包） |
| 特殊选项 | 下单勾选、影响用料/工序/计件系数的选项集合（§1 清单 19 项） |
| 主布 | 拼色窗帘的主体面料（大身）；明细行角色之一 |
| **配布边** | 用**配布**做边的那条**面料明细行**；口语叫「**加窗边布**」。双拼时与主布并列成行 |
| **接高** | 面料高度不足时接一段补高；按**明细行**归属（主布接高 / 配布边接高） |
| 双眼皮接高 | ERP 专有勾选项，**含义待查明**（2026-09-18 客户亦不明）—— **不得凭字面推** |
| 立边 | 侧边折边并推入花边/装饰条（工序 `立边-布`）；与「配布边」**分层**（前者是工序，后者是面料行） |
| 拼2次 | 一条拼接缝（工序 `拼2次-布`）；口语叫「**双拼色**」 |
| 绷带 | = **绑带**（系帘绑带）的口语叫法；工序 `绑带-布` / `绑带-纱` |
| **面料米数** | ERP 订单头字段：**Σ 各面料行米数**（主布 + 配布边 + 纱） |
| **加工费米数** | ERP 订单头字段：**= 主布行米数**（配布边米数**不参与**加工费）；与「面料米数」是两个独立字段 |
| 工艺规格 | 订单行承载的工艺参数集合（部位/工艺/加工类型/打开方式/定型/款式/褶距/对花/特殊选项 + 算料输出） |
