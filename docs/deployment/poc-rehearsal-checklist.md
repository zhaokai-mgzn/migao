## 1. 第 2 幕 · 小布算料报价（核心，8 分钟）

**顾客机话术（逐字）：**
1. `3米宽的窗，2倍褶皱，遮光布，帮我算下要多少钱`
2. 加戏：`我家窗户有点高，2.7米高窗，还是遮光布呢`

| 项 | 期望 |
|---|---|

| 输出 | 报价单**卡片**（明细行 + 合计 + 确认下单按钮），非纯文本 |

- [ ] 1.1 面料米数与明细数字全对（对不上立刻记下偏差值）
- [ ] 1.1 输出是 QuotationCard 卡片

## 9. 风险台账（发现即记）

| 风险 | 现象 | 处置 |
|---|---|---|
| 算料偏差 | 米数/总价 ≠ 速查真值 | 记录偏差值与话术，立即查 curtain_calc/取价，不放过 |
| 下单不落库 | 后台不见新订单 | 查 order_create 权限/SKU 取价（M3）/SMS bypass，P0 拦截 |
| 图片答非所问 | vision 未走通 | 换演示素材图重试；备录屏兜底 |
| LLM 发散/延迟 | 答非所问/首轮 >8s | 只走脚本话术；预热；录屏兜底 |
| 订单列表太杂 | 彩排测试单堆积 | 演示前清理或当天先产生 |
