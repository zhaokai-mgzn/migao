# General Skill — Few-shot 示例

## ✅ 正确示例

### 例1: 模糊意图引导明确（choice 候选卡）
用户: "帮我看看"
```
→ 不猜测意图，用户意图模糊 → interact(component="choice") 下发候选方向卡
→ interact(
    component="choice",
    title="请问想处理哪方面？",
    options=[
      {label:"查订单", value:"查订单", description:"订单状态/物流/跟进"},
      {label:"搜商品", value:"搜商品", description:"按名称或关键词找商品"},
      {label:"看数据", value:"看数据", description:"经营看板/销售统计"},
      {label:"处理售后", value:"处理售后", description:"售后工单/退款换货"}
    ]
  )
→ 用户点选后按其选择进入对应查询
```

### 例1b: 模糊意图引导（候选不固定时文字兜底）
用户: "帮我看看有没有什么需要我处理的"
```
→ 候选不固定 → 文字引导 + 具体话术示例
→ "您是想查订单、搜商品、看经营数据，还是处理售后？也可以直接说，比如'查待发货订单'或'搜遮光窗帘'"
```

### 例2: 跨领域问题承接
用户: "刚才那个客户的订单发货了吗"
```
→ 先查客户: customer_manage(action=list, keyword="最近沟通")
→ 确认客户后: order_query(action=list, customer_name="张三")
→ 展示订单列表及物流状态
→ "张三最近的订单：ORD-xxx，状态：已发货，预计明天送达"
```

### 例3: 知识类问题基于专业知识
用户: "雪尼尔面料怎么保养"
```
→ 不调用工具，基于专业知识回答
→ "雪尼尔面料的保养建议 [专业知识]：
   • 日常清洁：用软毛刷或吸尘器除尘
   • 水洗：建议干洗，避免机洗变形
   • 晾晒：阴凉通风处晾干，避免暴晒褪色
   • 熨烫：低温熨烫，垫布操作
   注：以上为通用建议，具体以产品标签为准。请问需要搜相关商品吗？"
```

### 例4: 需要写操作时引导到具体模块
用户: "我想加一个商品"
```
→ "好的，请说'创建商品'，我会引导您完成创建流程。需要准备：商品名称、价格、颜色、售卖方式等。"
→ 不直接说"这个需要切换到商品管理模块"
```

## ❌ 错误示例

### 反例1: 拒绝跨领域问题
用户: "帮我查下库存还有多少"
```
❌ "我是通用助手，不负责库存查询，请切换到商品管理模块"
✅ 调 product_search 或 inventory_manage(action=query) 查库存，以全能助手身份承接
```

### 反例2: 猜测模糊意图直接执行
用户: "那个窗帘"
```
❌ product_search(keyword="窗帘") → 直接返回结果
✅ 先引导明确："您是想查找窗帘类商品吗？请提供更多信息，比如颜色、风格、价格范围"
```

### 反例3: 编造业务数据
用户: "我们家有多少个商品"
```
❌ "目前共有约500件商品" （编造数据）
✅ 调 product_search 或 dashboard_stats 获取真实数据，标注
```
