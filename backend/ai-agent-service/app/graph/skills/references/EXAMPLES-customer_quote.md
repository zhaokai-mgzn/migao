# Customer Quote Skill — Few-shot 示例（小布 · C端算料报价）

> 轨迹里出现的工具必须都在本 skill 工具集内（`curtain_calc` / `product_detail` /
> `product_search` / `interact`）。本 skill **没有下单能力**，算完一律交回下单流程。

## ✅ 正确示例

### 例1: 顾客选了本店商品 → 先取真实单价，再算料，先总价后明细
顾客: "我看中你们那款雪尼尔遮光窗帘，窗宽3米、窗高2.5米，帮我算算要多少钱"
```
→ product_search(keyword="雪尼尔遮光窗帘") → 命中 1 款
→ product_detail(product_id="xxx") → 单价 ¥98/米、门幅 2.8 米、大花型（需对花）
→ curtain_calc(window_width=3, window_height=2.5, mounting="eyelet", fullness=2,
               fabric_width=2.8, fabric_price=98)
→ 工具返回 fabric_meters=6.6、total=973.6、warning=""（无告警）
→ "亲，这款帮您算好了~ 这套窗帘总价约 **¥974**，需要用布 6.6 米。
  大意是：面料约 ¥647，加工约 ¥53，辅料+安装约 ¥274。
  这是按您给的尺寸预估的，到店测量会更精确~ 觉得合适的话，点下方【确认下单】或回复「我要下单」，我帮您安排～"
→ （顾客确认下单 → 只回"好的～我这就为您安排下单，请稍等"，由下单流程接手，
   不要在本技能收集收货信息）
```

### 例2: 顾客自己报了布价 → 不必查商品，直接算
顾客: "3米宽2.5米高，2倍褶皱打孔帘，用98元一米的遮光布，帮我算多少钱"
```
→ 顾客已给全尺寸 + 款式 + 布价 → 不需要 product_detail
→ curtain_calc(window_width=3, window_height=2.5, mounting="eyelet", fullness=2,
               fabric_width=2.8, fabric_price=98)
→ "亲，总价约 **¥974** 哦~ 这套用布 6.6 米（面料约 ¥647 / 加工约 ¥53 / 辅料+安装约 ¥274）。
  这是预估，实际以到店测量为准~ 需要我帮您安排下单吗？"
→ （顾客说"要"→ 交回下单流程，本技能不下单）
```

### 例3: 窗高偏高 → 工具走定宽买高并告警 → 用大白话说明，不隐瞒也不抛术语
顾客: "窗宽3米、窗高2.7米，2倍褶皱打孔帘，要对花（花距40厘米），用98元一米的布，要多少布多少钱"
```
→ curtain_calc(window_width=3, window_height=2.7, mounting="eyelet", fullness=2,
               fabric_width=2.8, fabric_price=98, has_pattern=true, pattern_repeat=0.4)
→ 工具返回 fabric_meters=10.2、total=1415.5、formula_used="fixed_width"、warning 非空
→ "亲，这套总价约 **¥1416**，需要用布 10.2 米~
  您家窗户比较高，要用更宽的面料来做，所以会多算一些布；加上这款是大花型、要对花，
  每幅还要多留一点花位，这部分也一起算进去了。
  （面料约 ¥1000 / 加工约 ¥82 / 辅料+安装约 ¥334）这是预估，到店测量会更精确哦~"
```
（⚠️ `warning` 非空时必须让顾客知道原因，但**禁止**直接抛"成品高超过门幅定高上限，已按定宽布计算"
这类术语原文；也**禁止**因为看不懂就把告警咽下去。）

## ❌ 错误示例

### 反例1: 没拿到真实单价就报价（凭默认价兜底 = 编造报价）
顾客: "窗宽3米、窗高2.5米，打孔帘，要多少钱"
```
❌ 不查商品、直接按"默认 30 元/米"估一个数报给顾客（口径与真实售价无关，属编造承诺）
✅ "亲，您想用哪一款布呢？告诉我款式或把商品发我，我按真实价格帮您算～"
   （顾客报了布价 → 直接用他的价；选了本店商品 → product_detail 取 price）
```

### 反例2: 把顾客说的"米数"当成窗户尺寸（多收 2~3 倍钱）
顾客: "我要买 3 米布，帮我算下多少钱"（选好布了，报的是购买数量）
```
❌ curtain_calc(window_width=3, ...) → (3+0.3)×2 = 6.6 米 → 按 6.6 米收钱（顾客只要 3 米）
✅ 3 米已经是**购买数量**，不是窗户尺寸：直接按 3 米 × 单价算这一笔，或直接走下单流程；
   要问的是"您家窗户多宽多高"（顾客是想确认用量时）
```

### 反例3: 在本技能里收集收货信息 / 尝试下单（走到不存在的工具 → 死路）
顾客: "算好了，我确认下单"
```
❌ 用 interact(form) 收姓名/手机号/地址，然后尝试调下单工具 → 工具不存在 → 反复重试 → 转人工，
   订单永远不会创建，顾客侧表现为"下单失败"
✅ "好的～我这就为您安排下单，请稍等" → 由下单流程接手收集收货信息（本技能无下单能力）
```
